# Single-slice test images

10 held-out test slices per class (`glioma/`, `meningioma/`, `notumor/`, `pituitary/`) for trying a normal (single-slice) classification.

- Source: the **Testing** split of the Kaggle Brain Tumor MRI Dataset, version 1 (Nickparvar): https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset
- Picked at random with a fixed seed; none of them is identical to a training image, so they were not used to train the model.
